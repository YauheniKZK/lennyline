# LennyLine

Игра LennyLine - аркадная игра, где нужно управлять персонажем, избегая препятствий и собирая квадраты.

## Технологии

- React
- Vite
- Canvas API

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка для продакшена

```bash
npm run build
```

## GitHub Pages

Проект автоматически деплоится на GitHub Pages при каждом push в ветку `main` или `dev`.

Для ручного запуска деплоя:
1. Перейдите в раздел Actions на GitHub
2. Выберите workflow "Deploy to GitHub Pages"
3. Нажмите "Run workflow"

После первого деплоя включите GitHub Pages в настройках репозитория:
1. Settings → Pages
2. Source: GitHub Actions

Сайт будет доступен по адресу: `https://yauhenikzk.github.io/lennyline/`
